# java-lotto-precourse

## 기능 구현 리스트

- [ ] 로또 발매 기능
  - [x] 로또 구입 금액을 입력받는다.
    - [x] 로또 구입 금액이 1,000원으로 나누어 떨어지지 않으면 예외 처리한다.
    - [x] 잘못된 입력이 들어오면 예외 처리한다.
  - [x] 발행할 로또 수량을 출력한다.
  - [ ] 로또 수량만큼 로또 발행한다.
  - [ ] 발행한 로또 번호를 오름차순으로 정렬한다.
  - [ ] 정렬한 로또 번호를 출력한다.
  - [ ] 당첨 번호를 입력받는다.
    - [ ] 입력된 당첨 번호가 1 ~ 45 사이의 숫자가 아니면 예외 처리한다.
    - [ ] 잘못된 입력이 들어오면 예외 처리한다.
  - [ ] 보너스 당첨 번호를 입력받는다.
    - [ ] 입력된 당첨 번호가 1 ~ 45 사이의 숫자가 아니면 예외 처리한다.
    - [ ] 잘못된 입력이 들어오면 예외 처리한다.
  - [ ] 로또 당첨을 판단한다.
  - [ ] 당첨 내역을 출력한다.
  - [ ] 수익률을 구한다.
  - [ ] 수익률을 출력한다.
